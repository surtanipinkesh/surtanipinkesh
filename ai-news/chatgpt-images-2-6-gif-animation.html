ChatGPT Images 2.6 now makes animated GIFs

OpenAI has released Images 2.6. ChatGPT and Codex can now turn a prompt or a still image into an animated GIF, keep reference images for reuse, and two new API models generate images about 50% faster.

By Papad Pixels · 3 min read

In 30 seconds

  • OpenAI released Images 2.6 on 4 November 2026 in ChatGPT and Codex, for all plans, on web, desktop and mobile.
  • It can turn a text prompt or an existing image into an animated GIF, with control over speed and individual frames.
  • People can save reference images of themselves, pets or characters and reuse them without uploading again.
  • Two new API models arrive: GPT-Image-2.6 Flare for speed and GPT-Image-2.6 Sunburst for quality.
  • OpenAI says the new models generate images about 50% faster than GPT-Image-2.5.

What happened

On 4 November OpenAI launched Images 2.6, the latest version of image generation inside ChatGPT and its Codex app. The headline feature is motion: for the first time ChatGPT can turn a written prompt or an uploaded still image into an animated GIF that plays on a loop.

The update also adds saved reference images, so a face, a pet or a character can be reused in new pictures without uploading it each time, and two new models for developers in the API that OpenAI says are about 50% faster than the previous generation.

The key details

  • Who can use it: everyone with ChatGPT or Codex, on all plans, on web, desktop and mobile. OpenAI's help pages say GIF creation is rolling out gradually, so it may appear later for some accounts.
  • GIFs: start from a prompt or an image, change the playback speed, edit single frames, then save or share the loop.
  • Reference images: keep images of yourself, pets or characters ready to reuse, which helps keep a mascot or person looking the same across pictures.
  • API models: GPT-Image-2.6 Flare is the fast option, returning an image in as little as about six seconds; GPT-Image-2.6 Sunburst is the quality option, with more consistent results across edits at medium or high quality.
  • Speed: OpenAI says the new models are about 50% faster than GPT-Image-2.5.
  • Limits and price: OpenAI has not said how many GIFs each plan allows, and outlets report API pricing differently, so check OpenAI's own pricing page before you plan volume.

The background

Image generation is one of ChatGPT's most used features, and OpenAI has been updating it every few months. Animated GIFs are a step toward moving images inside ChatGPT itself, short of full video.

OpenAI is also building an ad business inside ChatGPT. Last week ChatGPT Ads switched on AI rewriting of ads by default (see our story on ChatGPT Ads creative enhancements), so the same company now offers tools both to make visuals and to change ads after launch.

What it means for brands

For marketers this is a quick, cheap way to add movement: a product photo that gently loops for an email header, a mascot that waves in a story, or a moving mock-up to test an idea before spending on production. Saved references also make it easier to keep a character or product looking the same across a set of images.

A GIF is still not a finished ad. Short loops have no sound, limited length and lower quality than video, and paid social still rewards proper vertical films with a hook, a story and sound. Use Images 2.6 to sketch and test ideas fast, then turn the winners into real AI social media videos made for each platform.
